# WDD 430 Portfolio

A personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Live Website

https://wdd430-portfolio-ten-tau.vercel.app/

## GitHub Repository

https://github.com/ghrwn/wdd430-portfolio

## Features

- Home page introducing the developer
- About page describing the learning journey
- Reusable Header, Footer, ProjectCard, and ProjectList components
- Custom SkillsCard component
- API route that returns a JSON message
- Responsive layout using Tailwind CSS

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## API Route

Visit `/api/hello` to see the API response:

```json
{
  "message": "Hello from Next.js API!"
}
```
